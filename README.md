## Descrição/Justificativa do Projeto

É perceptível uma deficiência no acesso à informação de cursos e formação profissional, desta forma, foi pensado um projeto que pudesse solucionar o problema. 

O desenvolvimento do sistema de divulgação de cursos permitirá acesso a informação, inclusão social e crescimento profissional.
